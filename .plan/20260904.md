**A. 实现 `scripts/daily_report.py` 飞书日报生成脚本**

- `scripts/daily_report.py` — 新增日报生成器

  - 输出:Markdown 格式日报,4 段结构:
    1. **Top 10 热度议题**(按 heat_score 倒序,id / name / category / heat)
    2. **近 7 日声量监控**(按 issue_id 聚合 pulse_snapshots,显示总声量 + 平均情感)
    3. **议题关系亮点**(出度 Top 3 / 入度 Top 3 议题)
    4. **报告元信息**(生成时间 / 数据日期范围 / 数据规模)
- CLI 形态对齐 `issue_summary.py` 风格(`--json` / `--strict` / `--date`)
- 默认输出到 stdout,可用 `--output` 写入文件
- 复用 `issue_summary.py` 已有的 `load_issues` / `load_relations` 风格,保持代码一致性
- 复用 `validate_pulse.py` 风格,数据缺失给出明确错误提示
